# Digital Piggy Bank 🪙

A beginner Python mini-project practicing Object-Oriented Programming (OOP) principles by building a virtual savings account.

## 📌 Description
This project defines a `PiggyBank` class that bundles an account owner's balance with methods to add and spend money safely, preventing negative balances.

## ✨ Features
- **Deposit funds (`add_money`)**: Adds money to the current balance and prints a confirmation.
- **Spend funds (`spend_money`)**: Checks for sufficient balance before deducting money, displaying an error if funds are low[cite: 1].
- **Isolated Account Instances**: Keeps tracking and balances separate across multiple user accounts[cite: 1].
